# Rules that change with the law

- wanderbooks knows some legal amounts (like the 1099 threshold) only through a given year and never guesses past it.
- When a tool refuses with "wanderbooks knows the ... only through", or books.digest lists stale_rules: check today's date, find the current figure from the official source (the refusal names it) or ask the human (owner, CPA), confirm it with them, and pass it explicitly.
- Then tell the human, who can report the new value and its official source upstream so the rule is updated for everyone.
