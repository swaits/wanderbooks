# ISO 4217: currency minor units

Governs `Currency::minor_units`, which sets the smallest unit a ledger
books in (rules.md B-3): foreign-currency lines are rounded to it.

Source: ISO 4217 "list one" (current currency & funds), published
2026-09-17 by SIX Financial Information, the ISO 4217 maintenance agency.
<https://www.six-group.com/dam/download/financial-information/data-center/iso-currrency/lists/list-one.xml>,
retrieved 2026-10-13, SHA-256
`33139b438657d1cee116ba737807ea71d19d6de4b90f799a09c56f0cc6a1b0ff`.

The list itself is ISO's, so it is not reproduced here; these are the facts
the code uses, generated from it (the `CcyMnrUnts` of each `Ccy`):
